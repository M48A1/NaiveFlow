# iOS 客户端界面

底部固定为首页、策略组、设置三个 Tab，使用系统蓝导航、动态系统背景和原生 SwiftUI 导航。

- 首页依次为“运行控制、我的配置、出站模式、PROXY、分流规则”五张卡片，运行控制固定展开，其他卡片默认折叠，分别使用淡青绿、淡紫、淡蓝、淡橙、淡粉渐变背景及深色文字（深色模式跟随系统）。点击配置、出站模式、PROXY 和分流规则卡片标题展开或收起明细；折叠时显示当前配置、模式或节点摘要，运行开关与流量明细始终可见，运行卡片不提供折叠交互。不提供折叠箭头或右上角添加菜单。新建、导入、配置管理位于配置卡片底部同一行，URL 和文件导入合并为导入菜单；测速、节点管理位于节点卡片底部同一行，不再提供独立添加按钮，延迟测试和测速后自动选择合并为测速菜单，管理入口使用文字按钮，不带右箭头。普通节点选择无需跳转。首页没有 MITM 或模块入口。
- 策略组为双列渐变卡片。支持手动选择、URL Test、Fallback、Load Balance，及组编辑、复制、排序、成员管理、图标和配色。内核状态通过只读 IPC 查询，读取状态不消耗轮询选择次数。
- 设置集中管理 DNS、始终保持连接、局域网共享、运行日志、请求记录、MITM、模块、证书、Hostname、通知和通用选项。不提供外观自定义、Data 或 Country Bypass。

## 配置与运行状态

`ClientModel` 管理界面会话；`ClientProfileLibrary` 原子保存命名配置文件及远程地址、模块来源、组配色等编辑元数据，路径为 App Group 的 `configurations/client-ui/profiles.json`。这些元数据不承担路由决策。

所有网络行为通过当前文本文档编译并交给 `ConfigurationPublisher` 发布。`ClientDocumentEditing` 负责定点修改键值、组成员和顺序；常规编辑保留其他文档内容。重命名节点或策略组时同步更新引用；删除仍被引用的项目时拒绝发布，显示具体原因。

`[General] default-node = Name` 明确指定 PROXY 和全局代理的默认节点，也支持代理链名称。无此字段时延续已有默认节点选择规则。每次选择都发布完整运行版本，不修改旧的独立手动设置。

保存配置草稿不会改动当前显示的运行模式或节点。应用错误会保留原运行版本；运行开关仅在已有有效配置且隧道管理器就绪时可用。

## 模块与导入

支持 Surge / Quantumult X 模块，从源文本、HTTPS 或本地文件载入。发布前解析并验证模块及脚本，将模块作为具名 `[MITM Set]` 规则写入同一配置。独立开关修改该组规则的 enabled 字段，更新模块重新解析源文件。遵循当前 MITM 内核的作用域、脚本和证书约束。

节点可从分享链接、Base64 节点列表、受支持的订阅格式或原生配置载入。HTTP 导入先验证响应；本地文件仅做内容解析。新增内容发布后才改变运行节点列表。

日志支持查看、系统分享和清除内核缓冲。通知默认关闭，用户授权后可在后台接收连接状态变化。浅色、深色和动态字体跟随系统设置。

## 首页分流规则

PROXY 下方的分流规则卡片默认折叠，摘要显示 RuleSet 和 Local 数量。展开后并排显示两张小卡片：RuleSet 对应当前配置的 RULE-SET 引用，Local 对应其余本地规则（含 FINAL）。点击进入明细，按配置顺序显示条件、策略及选项，可通过“编辑配置”打开当前配置编辑器。

RuleSet 和 Local 页面右上角统一使用“+”图标。RuleSet 的“+”提供新建入口，Local 的“+”沿用当前配置编辑入口。RuleSet 通过半屏编辑窗口填写规则集地址、选择策略组或 PROXY / DIRECT / REJECT，并设置 no-resolve；点击已有规则集可编辑。保存走当前配置发布流程，下载及语义校验失败时保留原运行版本。新增引用插入 FINAL 前，编辑保留行尾注释和其他规则选项。

## 节点 QUIC 与外部图标集

设置中不再显示全局 QUIC 选择器；新建和编辑节点提供“关闭 QUIC”开关，节点偏好通过 block-quic 链接参数或节点字段写入配置并进入运行包。开关只影响经此节点转发的流量，不影响节点本身的 QUIC 传输。旧配置未设置节点字段时继续使用原全局策略，MITM 自动阻断和文本文档明确指定的全局 blocked 仍优先。

新建和编辑策略组时，图标设置合并为单一“图标”入口，显示当前图标预览，点击打开持久保存的图标集列表；不再展示默认图标列表或单独图标地址输入框。图标集列表预置离歌图标包的 JSON 地址。左滑可编辑地址、更新或删除，支持添加其他 HTTPS 图标集；点击浏览可搜索、滚动并选取图标，将图标 URL 填入当前策略组草稿，保存策略组后生效。兼容 name / description / icons（name、url）格式，下载限 4 MiB，失败保留已缓存内容。

首页隐藏独立导航大标题，运行卡片直接位于安全区域顶部。卡片标题固定为 NaiveFlow，连接成功时绿色，停止或尚未连接成功时红色；无障碍标签继续读出运行状态。策略组空状态不再显示额外“新建策略组”按钮，新增入口保留在右上角“+”菜单。

策略组详情的延迟测试入口位于顶部彩色卡片右上角，点击测试当前组内节点，期间显示测速进度并防止重复点击；节点行优先显示本次手动测试结果。详情不再显示“节点管理”，PROXY 详情移除原底部操作卡片，其他策略组保留自动选择。

新建节点默认协议为 AnyTLS，协议候选按 A–Z 排列；Nowhere 独有的 TCP / UDP 选择保持不变。节点编辑底部提供“通过此节点进行链式代理”，选择已有非 Direct 节点作为前置，显示本机 → 前置节点 → 当前节点 → 目标路径。underlying-proxy 以节点名称写入链接或原生字段，编译时解析为实际链路，拒绝缺失引用、自引用、循环和超过 16 跳的链路。重命名前置节点同步更新引用，被引用的节点不能直接删除。

设置首页直接显示“始终保持连接”开关和“局域网共享”入口，移除“网络”二级菜单及其余网络选项界面。始终保持连接仍通过 always-on 写入当前配置；局域网共享沿用现有 LAN 代理设置页。

## Geo 数据源设置

设置首页增加 GeoIP 与 GeoSite 两个独立入口，可新增、编辑和删除数据源，维护更新地址、分类标识、格式、DAT 来源分类及可选 SHA-256，显示当前运行版本的加载时间。保存会下载、校验并应用配置。手动更新重新应用当前配置，刷新所有显式外部资源；失败保留原运行版本。内联 Geo 数据保持不变，删除仍被规则引用的数据源会被校验拒绝。没有预设联网数据源，也不启用自动更新。

## 界面语言

应用界面仅提供英语：标题、按钮、说明、无障碍标签、通知及应用自身的错误提示均使用英语。字符串目录只保留英语资源，各产品声明 en 本地化，iOS / macOS 的 SwiftUI 根视图固定英语 locale。节点、策略组、配置等用户自定义名称与外部数据内容保持原样。
